# Studio marks

The DreamStream mark family: the house mark and one mark per studio, plus Atlas Studio's mark so the
studio switcher can show every studio. Code: `components/brand/` (`StudioMark`, `StudioLogo`,
`studio-marks.css`, geometry in `studios.ts`). Icons and favicons: `public/icons/`, generated by
`scripts/gen-icons.mjs`. Approved family sheet:
[`assets/studio-marks-family-sheet.png`](assets/studio-marks-family-sheet.png).

| Studio | Mark | The point is | Hover / loading moment |
|---|---|---|---|
| DreamStream Studio (house) | **D**: the D with the point in its counter | the house spark | the point drops in like a pin |
| Comic Studio | **Grin**: the D tipped onto its back laughs | the eye, glancing | the eye blinks |
| Stream Studio | **On air**: the D's bowl mirrored around the point | the live source | the arcs broadcast; looped, the point pulses |
| Atlas Studio | **A**: the open A (no crossbar) | "you are here" | the pin drop (as in Atlas) |

## Construction: one tile, one cut, one point

Every mark is drawn exactly like Atlas's `AtlasMark` (`components/AtlasLogo.tsx` in Atlas):

- **One tile.** A 64 × 64 viewBox and one `rect` with `rx 16`, filled with `currentColor`.
- **One cut.** One stroke of weight **7**, mitred corners, butt ends, cut *out* of the tile through a
  `<mask maskUnits="userSpaceOnUse">` (white rect keeps, black stroke cuts). There is no second fill
  colour, so one drawing is right on white, on black and on inverted panels. Atlas draws in straight
  lines; the DreamStream curves are radius 16, the tile's own corner (On air adds a 0.5 optical
  overshoot for the round form).
- **One point.** A circle of radius **3.6**, also cut out, and it always has a job (table above).
- **Same weight.** Atlas and both studios cut about 13–16% of the tile, with centroids within 0.6
  units of Atlas's; the D (19.5%) runs heavier on purpose, it is the parent mark.

| Mark | Cut (centre line) | Point |
|---|---|---|
| D | `M21 16 L31 16 A16 16 0 0 1 31 48 L21 48 Z` | 33, 32 |
| Grin | `M16 27.5 L48 27.5 A16 16 0 0 1 16 27.5 Z` | 24, 15.9 |
| On air | `M40.99 18.16 A16.5 16.5 0 0 1 40.99 45.84 M23.01 45.84 A16.5 16.5 0 0 1 23.01 18.16` | 32, 32 |
| A | `M16 50 L32 14 L48 50` | 32, 40 |

## Using the components

Both components are framework-free: they are styled only by `components/brand/studio-marks.css`
(imported by the components themselves), so they render the same in the main app and in Stream
Studio's plain-CSS bundle. They draw in `currentColor`: set the text colour of the surface, never a
fill.

```tsx
import { StudioLogo, StudioMark } from '@/components/brand';

<StudioLogo studio="dreamstream" />                    // header lockup: mark 32, text 20
<StudioLogo studio="comic" size="display" />           // hero / splash: 56 / 34
<StudioLogo studio="stream" size="compact" />          // tight headers, menus: 28 / 17
<StudioLogo studio="stream" endorsed />                // DREAMSTREAM overline over "Stream Studio"
<StudioLogo studio="comic" showLabel={false} />        // the mark alone, named "Comic Studio"
<StudioMark studio="stream" size={20} />               // decorative (a label is beside it)
<StudioMark studio="atlas" label="Atlas Studio" />     // standalone: role="img", aria-label
<StudioMark studio="dreamstream" size={48} loading />  // splash / route loading
```

**`StudioMark`** props: `studio` (`'dreamstream' | 'comic' | 'stream' | 'atlas'`), `label?`,
`loading?`, `size?` (number = px, or any CSS length; default 1em), `className?`, `style?`.
Mask ids come from `useId()`, sanitised to id-safe characters, so any number of marks can share a page.

**`StudioLogo`** props: `studio`, `size?` (`'header'` default, `'display'`, `'compact'`), `endorsed?`
(Comic and Stream only; ignored for the house mark and Atlas), `showLabel?` (default true),
`loading?`, `className?`, `markClassName?`, `labelClassName?`, `style?`. The wordmark is
"`<First>` Studio" in Space Grotesk 600 with −0.025em tracking, "Studio" at weight 500 and 55%
opacity; the overline is the overline recipe (11 px, 600, 0.12em, uppercase, 55%) in IBM Plex Sans.
Both faces are fixed, not read from `--ds-font-display` / `--ds-font-sans` (outside the Atlas skin
those are Inter), so the lockup looks the same on every host. The visible text is the accessible
name (inside a link it names the link); `translate="no"` keeps machine translation off the brand
name. Other sizes: set `--ds-logo-mark-size`, `--ds-logo-text-size` and `--ds-logo-gap` from a class
(`className="[--ds-logo-mark-size:28px]"`) or `style`, or size the parts directly
(`markClassName="h-7 w-7"`, `labelClassName="text-[17px]"`). Every lockup default sits in `:where()`
(zero specificity), so a class wins whatever order the stylesheets load in.

**Fonts.** The wordmark needs Space Grotesk 500/600 (and the overline IBM Plex Sans 600) loaded by the
page: `index.css` declares them for the main app, with or without the skin. Stream Studio self-hosts
the same `/fonts/*.woff2` (`live/styles/atlas-skin.css` declares them; `live.html` preloads the weights
the lockup uses). Where neither is loaded the lockup falls back to `system-ui`.

**Motion** (`studio-marks.css`, the Atlas logo's): hover tilts the tile −6° and 1.05 on
`--ds-ease-spring` over `--ds-motion-panel`; a press squeezes it to 0.94 over `--ds-motion-fast`;
each studio's moment runs inside the mask (the tile never changes colour). Hover applies inside a
`.ds-logo`, or when the mark or lockup is the direct child of a hovered link or button, and only on
devices that can hover. `loading` loops the moment; loops pause under any `[data-inview="false"]`
ancestor, so wrap a loading mark that can scroll off screen. Set the attribute yourself for now;
`useInViewPause` / `InViewPause` (`components/ds`) will set it once the shared token commit lands. Under
`prefers-reduced-motion: reduce` nothing moves. Every token is read with its Atlas value as fallback,
so the marks move the same where no `--ds-*` token exists.

### Do

- Use the studio's own mark on its own surface (Comic Studio header → `comic`, Stream Studio → `stream`)
  and the D for the suite.
- Use `endorsed` inside a studio when the DreamStream name is not already on screen.
- Give a standalone mark a `label`; leave it out when a wordmark or visible name is beside it.
- Keep at least a quarter of the mark's size clear around it, and keep it on one flat surface colour.

### Don't

- Don't colour the mark (hue is only for status in Atlas), outline it, add a shadow or a second fill.
- Don't redraw, rotate, stretch or re-space the glyph, or swap the point for another shape.
- Don't use the mark below 16 px; below 24 px drop the wordmark or use `compact`.
- Don't set the wordmark in another face or weight, or put "Studio" at full strength.
- Don't use the Tailwind `font-display` class for the wordmark (it means Bangers here).

Raster icons put a paper glyph on an ink tile: a transparent cut would show a dark launcher's colour
through the glyph. Colours are Atlas ink `#0a0a0a` and paper `#ffffff` (the favicon's dark-chrome
tile is `#fafafa`, as in Atlas's `app/icon.svg`). `comics-og.png` (the comics host's link preview)
still carries the pre-Atlas art; it is generated by `comics-edge/scripts/gen-comics-icons.mjs` and is
redrawn with the apex skin.

### Regenerating

```sh
npm run gen:icons                    # rewrite every icon and favicon from the three source marks
node scripts/gen-icons.mjs --check   # exit 1 if a committed output is stale
```

To change a mark: edit its source in `public/icons/*-mark.svg` (it must stay a 64-unit rx 16
`currentColor` tile with one weight-7 cut and one r 3.6 point in a `userSpaceOnUse` mask: a white
64 × 64 rx 16 keep rect, a black stroke-only cut with mitred corners and butt ends, a black point;
the generator refuses anything else, naming what is wrong), put the same numbers in
`components/brand/studios.ts`, run `npm run gen:icons`, and commit the sources with the outputs.
`tests/config/appIcons.test.ts` fails if the sources and `studios.ts` disagree, if an output differs
from what the sources make (SVGs byte for byte, rasters pixel for pixel within 2/255, so another
libvips build is not drift), if any manifest, page head, the comics edge or app code points at a
missing icon or one whose real format or size differs from what it declares, if a generated icon is
used by none of them (except the Stream files step 2a wires and `/stream-studio.svg`, kept for old
links, both listed in the test), if `/favicon.ico` is not a real ICO, or if maskable art leaves the
safe zone.
`tests/config/studioMarksGuard.test.ts` keeps `components/brand/**` free of the legacy comic kit,
hue and Tailwind, and holds the motion contract above.
