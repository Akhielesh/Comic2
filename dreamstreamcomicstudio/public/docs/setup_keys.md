# How to Get Your API Keys

DreamStream Comic Studio requires API keys for AI image and text generation. Follow this guide to get your keys.

## 1. Google Gemini (Text & Basic Image)
Used for: Script analysis, story generation, and basic panel prompts.
**Cost**: Free tier available!

1.  Go to [Google AI Studio](https://aistudio.google.com/app/apikey).
2.  Click **Create API Key**.
3.  Copy the key string (starts with `AIza...`).
4.  Paste it into DreamStream Settings -> **Gemini API Key**.

## 2. Pixazo / Flux (High Quality Images)
Used for: High-definition panel generation.
**Cost**: Paid (Pay-per-generation).

1.  Go to [Pixazo.ai](https://pixazo.ai) (or your Flux provider).
2.  Sign up or Log in.
3.  Go to **API Settings** / **Dashboard**.
4.  Generate a new **API Key**.
5.  Paste it into DreamStream Settings -> **Pixazo Flux Schnell Key**.

---
**Security Note**: Your keys are encrypted on your device and stored securely. We do not use them for anything other than generating your comics.
